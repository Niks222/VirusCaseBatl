# 👑 LECTOR CASES & CASE BATTLE | Telegram Mini App

> Полноценный Telegram Mini App (Web App) для открытия кейсов, кейс-батлов и выбивания **Telegram Подарков (Gifts), редких NFT и Звёзд (Telegram Stars)**.  
> Главный маскот проекта — **LECTOR** из BS (Black Spruit) с светящимся нимбом и фирменным стилем.

---

## 📸 Скриншоты и Визуальный Стиль
- **Маскот:** Lector BS (парень в белой балаклаве с черными потеками вокруг глаз и нимбом, стритвир эстетика).
- **Интерфейс:** Тёмная неоновая премиум-тема в стиле RubUp (глубокий обсидиановый фон `#0b0d18`, карточки с плавающими 3D-предметами, динамические свечения редкостей).
- **Дропы:** Официальные Telegram Gifts (мишки, розы, духи, часы, кольца, шампанское), NFT (Пёс Сопротивления Дурова, Неоновый Фламинго, Редо Череп, Маска Лектора), паки Звёзд (от 15 ⭐ до 5000 ⭐).

---

## ⚡ Основной Функционал

1. **📦 Открытие Кейсов (Case Opening):**
   - Плавная горизонтальная рулетка с замедлением (Cubic-Bezier) и реалистичным тиканьем звуков через Web Audio API.
   - Категории: *Все*, *Подарок дня (Free Daily)*, *На сдачу (Мелочь, Сдача, Копилка, Заначка)*, *Сопротивление (Пёс Сопротивления, Редо)*, *50/50 (Мишка или Торт, Роза или Алмаз)*, *Lector BS VIP*.
   - Шансы каждого дропа в процентах прямо в карточке кейса.
   - Выбор режима: *Обычное открытие* или *Мгновенное (Fast Open)*.
   - После выигрыша: "Продать за ⭐/₽", "Оставить в инвентарь", "Апгрейд".

2. **⚔️ Кейс Батлы (PvP 1v1):**
   - Сражения против Lector Bot или других игроков.
   - Выбор раундов (1, 2, 3, 5).
   - Синхронное открытие кейсов: чей суммарный дроп дороже, тот **забирает все предметы себе**!

3. **⚡ Апгрейд Подарков (Upgrade Wheel):**
   - Выбор предмета из инвентаря + выбор желаемого дорогого подарка/NFT.
   - Круговое колесо шанса с вращающейся стрелкой.
   - Расчет вероятности победы в реальном времени.

4. **🎒 Инвентарь и Вывод:**
   - Хранилище всех выигранных подарков.
   - Быстрая кнопка "Продать всё" или продажа поштучно.
   - **Кнопка "Вывод"**: ввод Telegram `@username` для отправки подарка через бота.

5. **🔥 Live Feed:**
   - Бегущая строка живых дропов игроков в реальном времени.

6. **⭐ Пополнение и Промокоды:**
   - Пакеты Telegram Stars и Рублей.
   - Промокод: `LECTOR` (дает **+150 ⭐** на баланс).

## 🚀 Как развернуть Mini App на GitHub Pages (Frontend)

Поскольку Telegram Web App требует обязательный **HTTPS-адрес**, самый простой и бесплатный способ — GitHub Pages:

### Шаг 1. Инициализация репозитория и пуш на GitHub
Выполните в терминале папки проекта:
```bash
git init
git add .
git commit -m "feat: initial Lector Cases Mini App"
git branch -M main
git remote add origin https://github.com/ВАШ_НИК/ИМЯ_РЕПОЗИТОРИЯ.git
git push -u origin main
```

### Шаг 2. Включение GitHub Pages
1. Перейдите в ваш репозиторий на GitHub → вкладка **Settings** → слева раздел **Pages**.
2. В **Build and deployment** → **Source** выберите:
   - **GitHub Actions** (в проекте уже лежит настроенный `.github/workflows/deploy.yml`), Либо:
   - Если хотите вручную: соберите фронтенд `npm run build` в папке `frontend` и выберите ветку с папкой `frontend/dist`.
3. После завершения workflow вы получите постоянный HTTPS-адрес:  
   `https://ВАШ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/`

## 🤖 Как настроить Telegram Бота через @BotFather

1. Откройте в Telegram [@BotFather](https://t.me/BotFather) и отправьте команду `/newbot`.
2. Введите имя и юзернейм для вашего бота (например, `LectorCasesBot`).
3. Скопируйте полученный **API Token** и вставьте его в файл `backend/.env`:
   ```env
   BOT_TOKEN=1234567890:AAH...
   WEBAPP_URL=https://ВАШ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/
   ```
4. Включите Mini App кнопку в [@BotFather](https://t.me/BotFather):
   - Отправьте `/mybots` → выберите вашего бота.
   - Нажмите **Bot Settings** → **Menu Button** → **Configure menu button**.
   - Отправьте ссылку на ваш GitHub Pages: `https://ВАШ_НИК.github.io/ИМЯ_РЕПОЗИТОРИЯ/`
   - Введите название кнопки: `🎮 Играть в кейсы`.

## 💻 Локальный Запуск

### Запуск фронтенда в режиме разработки:
```bash
npm run dev
```
Фронтенд запустится на `http://localhost:3000`.

### Запуск бэкенд сервера:
```bash
npm run start:server
```
Сервер запустится на `http://localhost:3001` (WebSocket + REST API).

### Запуск Telegram Бота:
```bash
npm run start:bot
```
Бот мгновенно начнет принимать команды `/start`, `/bonus`, открывать Mini App и обрабатывать платежи Stars.
